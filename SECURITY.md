# Security Policy

gamAI builds open agent infrastructure: **proof, immunity, honesty**.
Security is the product, not an afterthought.

## Reporting a Vulnerability

**Do not open a public issue for a security vulnerability.**

Report privately to: `security@gamai.io`

Expected acknowledgment: **72 hours** (business days).

Please include:
- Affected repository, component, and version
- A description of the vulnerability
- Steps to reproduce (or a proof of concept)

## Supported Versions

- `main` (default branch): always patched first
- Latest tagged release

## Disclosure

We ask for a reasonable coordination window (up to 90 days) before public
disclosure, and that you not access, modify, or exfiltrate data beyond what
is needed to demonstrate the issue.
